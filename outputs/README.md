# Outputs

This directory is where pipeline runs write their artifacts:

- `tiles/` — intermediate tiled images
- `masks/` — segmentation mask overlays
- `detections.geojson` — georeferenced tree-crown detections (GIS-ready)
- `embeddings.npy` — per-crown visual embedding vectors
- `clusters.png` — 2D cluster visualization

Nothing is committed here beyond this README — outputs are regenerated by
running [`notebooks/demo_pipeline.ipynb`](../notebooks/demo_pipeline.ipynb)
or the individual modules under [`src/`](../src/), and are excluded via
`.gitignore` since they are derived artifacts, not source. Running the demo
notebook against the built-in synthetic data will populate this folder
locally with non-sensitive example outputs.
